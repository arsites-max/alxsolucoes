# ALX TI — Site institucional

Site estático responsivo para GitHub Pages. Serviços, contatos e clientes preservados a partir de http://www.alxinformatica.com.br. Atendimento nacional e oferta emergencial de até 36 horas informados pelo responsável pela solicitação; disponibilidade, escopo e prazo precisam ser confirmados pela ALX antes da contratação.

## Publicação

Publicar a raiz da branch main pelo GitHub Pages. Não configurar CNAME: o domínio atual permanece na hospedagem original até uma migração solicitada separadamente.

## Contato

O formulário compõe uma mensagem de WhatsApp e exige envio pelo visitante. Não existe backend, armazenamento, envio automático ou integração com o Portal Soma. Não inclui dados internos do Portal Soma. Fontes Google Fonts são externas, com fallback local.

## Atualização

Editar index.html para textos e contatos, styles.css para aparência e app.js para as interações. Assets vêm do site atual da ALX.
